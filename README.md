**Middleware, Validasi, dan Error Handling**

- **Middleware:** Mencatat method, URL, status response, dan durasi request.
- **Validasi:** Menggunakan Joi untuk memeriksa input biodata dan parameter ID.
- **Error Handling:** Menangani kesalahan dan memberikan response JSON yang terstruktur.
